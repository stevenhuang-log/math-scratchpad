# math-scratchpad

A running log of math observations, patterns, and conjectures — not a solutions manual.

This is where I write down what I notice while playing with problems: half-formed ideas, things that turned out wrong, and patterns I later proved (or couldn't).

## How it's organized

Each entry lives in `/observations`, named by date and topic.
